# Contributing to Gaming Protocol

Thank you for your interest in contributing to the `gaming-protocol` repository! We welcome contributions to help build and improve our Soroban smart contract infrastructure on Stellar.

## How to Contribute

### 1. Find an Issue
* Look through the [Open Issues](https://github.com/Stellar-contract/gaming-protocol/issues) tab to find tasks labeled for community contributors.
* Leave a comment on the issue you wish to work on so others know it is being addressed.
